# BCS502 Computer Networks (sample syllabus notes, written for this demo)

Credits: 4. CIE 50 marks, SEE 50 marks. Textbook: Forouzan, Data Communications and Networking, 5th edition.

## Module 1: Introduction and Physical Layer
Data communications, networks, network types (LAN, WAN, MAN), the Internet, protocol layering, the TCP/IP protocol suite and the OSI model. Transmission media: guided media (twisted pair, coaxial cable, fibre optic cable) and unguided media (radio waves, microwaves, infrared). Switching: circuit switching and packet switching.

## Module 2: Data Link Layer
Data link control: framing, flow and error control. Error detection and correction: block coding, Hamming distance, cyclic redundancy check (CRC), checksum. Media access control: random access protocols ALOHA, CSMA, CSMA/CD and CSMA/CA; controlled access; channelization. Wired LANs: Ethernet protocol, standard Ethernet.

## Module 3: Network Layer
Network layer services, packet switching, IPv4 addresses, classful and classless addressing (CIDR), subnetting, DHCP, network address translation (NAT). Forwarding of IP packets. Routing algorithms: distance vector routing (Bellman-Ford), link state routing (Dijkstra), path vector routing. Unicast routing protocols RIP, OSPF and BGP. Introduction to IPv6.

## Module 4: Transport Layer
Transport layer services, process-to-process communication, port numbers. User Datagram Protocol (UDP). Transmission Control Protocol (TCP): TCP segment, three-way handshake connection establishment and termination, flow control with sliding window, error control, TCP congestion control (slow start, congestion avoidance, fast retransmit, fast recovery), TCP timers.

## Module 5: Application Layer
Client-server and peer-to-peer paradigms. World Wide Web and HTTP, FTP, electronic mail (SMTP, POP3, IMAP), TELNET, Secure Shell (SSH), Domain Name System (DNS), SNMP.
