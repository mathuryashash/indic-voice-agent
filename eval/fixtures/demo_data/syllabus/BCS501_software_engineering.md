# BCS501 Software Engineering and Project Management (sample syllabus notes, written for this demo)

Credits: 4. CIE 50 marks, SEE 50 marks. Textbooks: Roger S. Pressman, Software Engineering: A Practitioner's Approach; Bob Hughes and Mike Cotterell, Software Project Management.

## Module 1: Software and Process Models
The nature of software, software engineering, the software process, software engineering practice, software myths. Process models: generic process model, prescriptive process models: waterfall model, incremental model, evolutionary models (prototyping and spiral model), concurrent models, the unified process.

## Module 2: Requirements Engineering and Modelling
Requirements engineering tasks: inception, elicitation, elaboration, negotiation, specification, validation. Developing use cases, building the analysis model, scenario-based modelling, UML use case diagrams, class-based modelling, CRC cards.

## Module 3: Agile Development
What is agility, agile process, the agile manifesto, extreme programming (XP), other agile process models: Scrum (sprints, product backlog, daily scrum meetings), dynamic systems development method, feature driven development. Principles that guide practice.

## Module 4: Project Management and Estimation
Introduction to software project management, project planning, stepwise project planning. Software effort estimation: problems with over and under estimates, basis for estimation, function point analysis, COCOMO II cost estimation model. Activity planning, network planning models, critical path method (CPM), PERT.

## Module 5: Software Quality and Testing
Software quality, McCall's quality model, ISO 9126, capability maturity model (CMM). Software testing strategies: unit testing, integration testing, validation testing, system testing, white box testing (basis path testing, cyclomatic complexity), black box testing (equivalence partitioning, boundary value analysis).
